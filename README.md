# Rats Collective

Minimal static website hosted on GitHub Pages at ratscollective.com.

- index.html: centered wordmark, nine cursor-reactive rats, Contact / Artists / Instagram links.
- artists/index.html and contact/index.html: short inquiry pages with email links.
- style.css: white and black, bold IBM Plex Mono with monospace fallbacks.
- script.js: pointer-driven motion, reduced-motion support, no idle animation.
- robots.txt, sitemap.xml, llms.txt and homepage Organization metadata support discoverability.

To update the site, commit and push to main. GitHub Pages deploys the repository root. CNAME contains ratscollective.com. Keep domain email records unchanged when adjusting website DNS.

The PNG is the original supplied logo. The SVG favicon is a simplified recreation. No build or backend is required. Email links open the visitor's mail app. Typography loads through Google Fonts.

## Service discovery
The Contact page contains five expandable service descriptions, backed by matching Service and OfferCatalog structured data. Shared Organization, WebSite and page identifiers connect the business, its pages and contact details. Artist management is described as an exploratory partnership, not an established roster. The public crawler summary in llms.txt mirrors these facts. Keep visible copy and metadata in sync when services change.
